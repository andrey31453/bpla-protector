## Как получены расшифровки

- Локальное распознавание речи: `faster-whisper 1.2.1`, модель `large-v3-turbo`, `compute_type=int8`, язык `ru`.
- Каждый файл распознан дважды — со словарём терминов (`initial_prompt`) и без него; совпавшие фрагменты считаются устойчивыми, расхождения вынесены в раздел «Спорные места» соответствующего файла.
- Спорные фрагменты дополнительно перепроверены на замедленном до 0.7× звуке.
- Записи короткие и бытовые: речь не дикторская, встречаются оговорки. Прямые цитаты по таким расшифровкам приводить нельзя — сначала требуется подтверждение автора записи.
