# Наши структуры лендингов

Здесь лежат структуры лендингов, которых нет в ТЗ директолога (`docs/Запросы для лендингов.txt`) или которые в нём не расписаны. ТЗ — карта страниц и блоков, но часть тем автор оставил «на уточнение у заказчика». Такие темы мы расписываем сами, чтобы не блокировать работу: лишняя страница сайту не вредит, а уточнения заказчика потом вносятся правкой данных страницы.

Правила те же, что и для остального контента:

- факты, цифры и формулировки — только из источников п.2 AGENTS.md, ничего не выдумываем;
- если данных нет (например характеристики рольставней), ставим пометку «уточнить у заказчика» и нейтральную формулировку в тексте, а не придуманную цифру;
- каркас блоков — по п.5.2 AGENTS.md: первый экран → проблема → что защищаем → типы конструкций → ограничения → материалы → работы → нормативная база → уровни защиты → сертификаты → кейсы → клиенты → гарантия → документация → тендеры → стоимость → FAQ → форма заявки;
- каждая такая структура — это страница внутри общего сайта, а не отдельный сайт (AGENTS.md п.5).
