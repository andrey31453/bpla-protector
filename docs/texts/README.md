# База текстов: инженерная защита объектов от БПЛА

Этот каталог — исходная смысловая база для лендингов, презентаций, коммерческих предложений и экспертных материалов. Это не готовые страницы: каждый файл содержит факты, объяснения, тезисы и формулировки, из которых можно собирать разные тексты под отрасль, тип объекта и уровень детализации.

## Как использовать материалы

- Сначала определяйте объект, защищаемые зоны и актуальный профиль угрозы, затем выбирайте релевантные блоки.
- Не переносите числовые характеристики, сроки, стоимость, радиусы или обещания результата без проектного расчёта и подтверждающих документов.
- Не называйте конструкцию «непробиваемой», «абсолютной» или гарантированно предотвращающей ущерб. Корректная задача ЗОК — снизить вероятность и последствия поражения в заданном расчётном сценарии.
- Для материалов о радиоэлектронном противодействии учитывайте требования законодательства, электромагнитную совместимость и полномочия эксплуатирующей организации. Основной предмет этого каталога — инженерные защитные конструкции.
- Технические решения, типоразмеры, состав материалов и крепления должны назначаться проектом после обследования.
