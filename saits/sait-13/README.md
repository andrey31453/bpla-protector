# `sait-13` — фортТех

Статический многостраничный лендинг: инженерная защита объектов от БПЛА (вынесенный рубеж, ЗОК) и локальная противоосколочная защита оборудования (ЗПБ). Двенадцать страниц: `index`, `mosty`, `npz`, `podstancii`, `zdaniya`, `okna`, `konstrukcii`, `zpb`, `proektirovanie`, `o-kompanii`, `ceny`, `kontakty`.

## Прежде чем трогать контент — прочитайте это

**[`docs/kontent-audit.md`](docs/kontent-audit.md) — разбор спорных утверждений сайта (аудит 30.09.2026).** Там короткий список P1–P6: кейсы, референсы ЗПБ с датами и протоколами, цены, противоречие по материалам, цифры по БПЛА, гарантия. В файле есть готовые `grep`-команды, чтобы за секунды выйти на нужные строки в `src/data/*.json` и не перечитывать данные целиком. Перед правкой формулировок или цифр сначала смотрите туда: часть пунктов ждёт ответа заказчика, и менять их «на своё усмотрение» нельзя.

## Стек и сборка

Nunjucks (композиция на сборке) + Tailwind CSS v4 (`@theme` в `src/style.css`) + Vite MPA, ванильный JS только как прогрессивное улучшение. Плагин Nunjucks — собственный, в корне сайта: `nunjucks-plugin.mjs`, подключается в `vite.config.js` вместе с `@tailwindcss/vite`.

```bash
cd saits/sait-13
npm install
npm run dev      # http://localhost:8013
npm run build    # dist/ (включая npm run stars — иконки/фавикон)
```

Из корня репозитория сайт собирается общим скриптом вместе с остальными: `cd saits && ./build.sh`.

## Где что лежит

```
saits/sait-13/
├─ index.html, mosty.html, ...       # тонкие обёртки: {% extends %} + уникальные блоки
├─ vite.config.js                    # MPA-входы, порт 8013
├─ src/layouts/base.njk
├─ src/partials/{head,header,footer,cta,breadcrumbs,page-hero,jsonld,brand}.njk
├─ src/macros/*.njk                  # карточки, таблицы, KPI, FAQ, материалы
├─ src/data/*.json                   # весь контент и цифры — единственный источник
├─ src/js/{main.js,modules/*.js}     # мобильное меню, табы, аккордеон, маска, форма
├─ src/style.css                     # Tailwind v4 @theme — токены сайта
├─ public/                           # изображения страниц (hero/, obekty/, ...)
└─ docs/kontent-audit.md             # аудит спорного контента, см. выше
```

Правила, важные для этого сайта:

- **Правим данные, а не разметку.** Тексты, цены, KPI, FAQ, кейсы, карточки, `title`/`description` — в `src/data/`. Ничего из этого в `.html` не хардкодится.
- **Контакты и домен — один файл.** Телефон, e-mail, адрес, `baseUrl` и OG-картинка живут в `src/data/site.json` и подставляются во все страницы, шапку, подвал, CTA и JSON-LD. Меняются там же, в разметке не хардкодятся.
- **Фотографии.** Кадры первых экранов и галереи «Объекты» взяты из `docs/images/` — это временные изображения, их заменяем своими снимками (`docs/images/README.md`).
- **Цифры — только из `docs/`.** Свои характеристики, сроки и гарантии не выдумываем: `AGENTS.md`, п.2.
