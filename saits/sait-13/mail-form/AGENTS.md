# Памятка для ИИ: переносимая отправка формы

Сначала прочитай `README.md` рядом с этим файлом.

Владелец выбрал **обычный PHP mail()**, без внешнего SMTP, msmtp, PHPMailer,
API-сервиса отправки и клиентских зависимостей. Не усложняй это без нового решения
владельца. На голом Linux mail() требует локальный MTA; для Debian/Ubuntu
подготовлен Postfix с прямой отправкой, PHP-FPM и nginx. Это не гарантия доставки.

Эту папку намеренно можно скопировать целиком в другой репозиторий.
Не читай соседний репозиторий самостоятельно. Не переноси бренд, домен, Gmail
и контакты текущего сайта автоматически. В `config/form.json` сейчас временный
получатель владельца для теста; уточни/замени его перед внедрением в другой проект.
Домен и бренд передаются сборщику из единственного источника данных целевого сайта.

Источники истины:
- `server/lead.php` — единственная реализация отправки;
- `client/form.mjs` — единственная реализация JS-улучшения;
- `config/form.json` — поля, статусы, получатель;
- `build.mjs` — создание двух файлов `api/lead*.php`;
- `deploy/` — конфигурации PHP-FPM/nginx и разовая подготовка сервера;
- `tests/` — автономные тесты с имитацией sendmail, без настоящих писем.

Конфигурация в base64 — **не шифрование**. Секретов здесь нет и быть не должно.
Не публикуй source-папку целиком в document root: выкладываются только два
созданных PHP-файла, обработчик исполняется, конфигурация недоступна по HTTP.
Публичная витрина GitHub Pages PHP не исполняет.

Текущее подключение в сайте 13:
- `nunjucks-plugin.mjs`: loadForm() в data.form, mailAssets() в generateBundle;
- `src/js/modules/form.js`: re-export initForm из комплекта;
- `src/partials/form.njk`: статическая разметка с data-* хуками;
- nginx подключает фрагмент комплекта через `/etc/nginx/snippets/site-lead.conf`;
- `deploy/install-tls.sh` устанавливает фрагмент;
- workflow копирует комплект в `/root/mail-form` рядом с `/root/deploy`.

Владелец разрешил запуск setup.sh штатным workflow при выкладке sait-13 в main.
Повторный запуск проверяет здоровье собственной установки по root-only маркеру;
существующий чужой MTA он не перезаписывает. SSH-пароля
в hosting.json нет: там имя GitHub Secret. Ранее локальный SSH был отклонён,
поэтому серверная установка и доставка пока не подтверждены.

При переносе исполни автономные тесты из README, затем тесты сборки проекта,
проверь реальный POST и входящие/спам. mail() == true означает только приём MTA.
Не сообщай «письмо доставлено», пока получатель или журнал доставки этого не подтвердит.
Публикация и изменение серверов — только по правилам целевого репозитория.
